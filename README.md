# Warp Brand Logos

Brand logo SVG assets for the Warp Design System.

## Eik

This project is published to Eik as `@warp-ds/brand-logos`.

The release workflow logs in to Eik and publishes the `logos` folder using `eik.json`.

## Releasing

1. Make a change to the `logos` folder.
2. Bump the `version` in `eik.json`.
3. Commit and push to `main`.
4. CI publishes the new version to Eik.
